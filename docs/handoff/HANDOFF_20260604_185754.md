## 3. CRITICAL DECISIONS

- **SSH-exec + file-sync, NOT `DOCKER_HOST=ssh://`.** DADS deploys with bind mounts; `DOCKER_HOST=ssh://` resolves them on the wrong fs. So the control plane generates files locally, **pushes via tar-over-SSH**, and runs `docker` on the remote over SSH. Pure-Go `x/crypto/ssh` → no `ssh` binary in the image.
- **`internal/executor` abstraction (Local vs Remote).** Every docker call goes through one interface; remote = `cd <remoteEnvDir> && docker …`. Keeps the local path identical.
- **Per-`(workspace,env)` host binding** (`workspace_host_envs`; `env=''` = workspace default). Resolution: explicit env row wins over `''`. Enables dev-local / prod-remote.
- **`.env` is host-authoritative** — never regenerated/overwritten on a deployed remote env; only the deterministic compose is pushed. Migration moves `.env` so secrets travel.
- **Migrations are async jobs** → completion fires an alert event (bell + SSE) + notification channels. Avoids tying the user to the page.
- **Per-host `workspaces_dir`** (global `REMOTE_WORKSPACES_DIR` is the default).
- **Security:** SSH keys AES-256-GCM encrypted (key = HKDF of `JWT_SECRET`); TOFU host keys.
- **Convention:** per-sub-phase commit + build/vet/test, then redeploy + verify, with checkpoint commits. UI verified by compile (static imports) + API checks when login isn't possible.

## 5. GOTCHAS & WARNINGS

- **SQLite single-conn pool (`SetMaxOpenConns(1)`):** NEVER run a query inside an open `rows` cursor loop → **deadlock** (hit in `hostExecutors`, fixed by reading ids first then closing). `_foreign_keys=on` IS set, so `ON DELETE CASCADE` works.
- **Preview/auth:** the Vite preview session drops across each backend redeploy (in-memory token). I authenticate API checks via `POST /api/auth/login` (admin/`verifypass123`) in `preview_eval`, but do **not** type into the login form.
- **Build-verify pattern:** throwaway `golang:1.25-alpine`, mount `src/backend`, run `go mod tidy` (go.sum is **not** committed — Dockerfile tidies at build), stub `cmd/server/dist/index.html` for the `//go:embed all:dist`.
- **PowerShell here-strings (`@'…'@`) break on embedded quotes** → commit via `git commit -F <msgfile>`.
- **CRLF working tree:** `gofmt -l` flags every CRLF file (benign — `.gitattributes` normalizes to LF). Distinguish real alignment issues by `tr -d '\r' | gofmt -d`.
- **`docker stats --no-stream` ≈ 2.6 s** → `/live-stats` and `/stats` take ~3 s locally (fan-out is parallel across hosts).
- **Host-socket sshd ≠ real remote** (same daemon). Use DinD for placement-sensitive tests.
