## 3. CRITICAL DECISIONS
- **Live-stats split out from `/api/stats`:** `/api/stats` does `du` (per-workspace dir size) + `docker info` — too expensive to poll every few seconds. New `/api/live-stats` is cheap (only `docker stats --no-stream` + `docker ps`/`compose ls` counts), polled at **4s** and **SSE-invalidated** on container events. Disk stays on the slow `/api/stats` (30s) because `du` can't run that often.
- **Network is a derived rate:** docker `NetIO` is cumulative; the frontend computes per-workspace throughput (B/s) from the delta between consecutive live samples (`prevNet` ref). Consistent with the env-card Network tile.
- **Project→workspace mapping done frontend-side:** `/api/live-stats` returns per-compose-project stats keyed by `{workspace}_{env}`; the dashboard aggregates using its known workspace list. Backend stays config-read-free.
- **`docker stats` parsed pipe-delimited** (`{{.ID}}|{{.CPUPerc}}|{{.MemUsage}}|{{.NetIO}}`) so multi-token fields don't break `strings.Fields`.
- **Go module path stays `github.com/dads/ui`** despite the `src/` rename — internal identifier, renaming would churn every import for no benefit.
